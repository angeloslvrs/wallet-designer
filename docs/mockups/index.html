Boarding Pass Studio — UI/UX direction mockups

▶ compare.html — every direction side by side, same screen, live and clickable

Five interactive prototypes sharing one tiny runtime (_proto.js). Open any file directly in a browser and click: nav, stepper, Front/Back flip, passenger switching, drawer, status change (split-flap in E), push button, input-mode tabs. The small dark bar in a corner jumps between screens; the URL hash deep-links one (e.g. d-recommended.html#flights).

Every direction has the same eight screens: Templates · Bindings review · Flight step · Passengers step · Issued · Flights (ops) · Design editor · Device log.

  1. A · Manifest, evolved — the current swiss paper/ink system with a persistent numbered left rail. Square corners, hairlines, hard offset shadows.
  2. B · Departure board — flights-first dark ops console with a side panel. Modern dark UI, amber accent.
  3. C · Studio canvas — Apple-like light UI, soft cards, the pass always center stage in a three-pane workspace.
  4. D · Recommended — C's three-pane canvas and flow, A's paper/ink/mono restraint and single blue accent.
  5. F · Studio dark (B × C) — C's rounded structure and three-pane canvas, B's flights-first departures board with side panel, iOS dark palette. Light/dark toggle bottom-right (also ?theme=light).
  6. E · Split-flap board — literal Solari board: black flap tiles, yellow headers, every change flips character by character.

Contact sheets and screenshots are gitignored; regenerate with the sheet-*.html pages. Re-render with ./_shot.sh <file> <screen>.
